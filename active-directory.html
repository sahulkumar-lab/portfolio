Active Directory

Skill

Overview

Active Directory (AD) is Microsoft's directory service used to manage users, computers, groups, and permissions across a Windows network domain. It's a core part of keeping access control organized and secure in an enterprise environment.

What this involves

  • Creating, modifying, and disabling user accounts and computer objects in Active Directory.
  • Managing security groups and distribution groups, and assigning appropriate permissions.
  • Resetting passwords and unlocking accounts through Active Directory Users and Computers (ADUC).
  • Applying and troubleshooting Group Policy Objects (GPOs) for login scripts, drive mappings, and security settings.
  • Organizing users and computers into Organizational Units (OUs) for easier management.
  • Assisting with domain join and leave operations for workstations.
  • Basic troubleshooting of authentication and login issues related to Active Directory.
