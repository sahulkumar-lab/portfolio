## 🛠️ Repository Structure & Files

The repository contains the following core files and assets:

### Core Pages (`.html`)
* **`index.html`** – Homepage introducing your background, summary, and quick navigation links.
* **`about.html`** – Personal bio, background, and professional overview.
* **`experience.html`** – Detailed work history, IT background, and professional timeline.
* **`contact.html`** – Contact form, social links, and communication channels.
* **`more-info.html`** – Additional details, certifications, or supplementary information.

### IT Services & Specializations (`.html`)
* **`active-directory.html`** – Active Directory management, user provisioning, and domain services.
* **`hardware-repair.html`** – PC/workstation diagnostics, troubleshooting, and component replacement.
* **`networking.html`** – Network configuration, routing, switching, and troubleshooting.
* **`remote-support.html`** – Remote desktop troubleshooting and client assistance.
* **`servicenow.html`** – ITSM ticketing, workflow automation, and incident management.
* **`windows.html`** – Windows OS administration, deployment, and optimization.

### Styles & Assets
* **`styles.css`** – Main stylesheet governing the layout, typography, and responsive design of the webfolio.
* **`image2.jpg`** – Visual asset / profile image used across the site.
