Windows 10/11

Skill

Overview

Windows 10 and 11 are Microsoft's desktop operating systems used across most corporate environments. Supporting them involves installation, configuration, troubleshooting, and ongoing maintenance to keep end-user systems running smoothly and securely.

What this involves

  • Installing and configuring Windows 10/11 on new and existing machines, including driver installation and OS activation.
  • Applying Windows updates and patches, and troubleshooting failed or stuck updates.
  • Diagnosing and resolving performance issues, blue screens (BSOD), and application compatibility problems.
  • Managing local user accounts, permissions, and user profiles.
  • Configuring system settings such as power options, display settings, and default applications.
  • Troubleshooting boot issues and disk errors using System Restore, Safe Mode, and Windows Recovery Environment.
  • Setting up and troubleshooting printers, peripherals, and shared network drives.
